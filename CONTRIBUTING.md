# Contributing

Help Prompt Coach improve final outputs without adding unnecessary work.

## A useful issue

Include a synthetic or redacted task, target model/settings if relevant, the original prompt, the proposed prompt, the observed output failure, and a concrete success criterion. Never upload secrets, private conversations, customer data or material you cannot share.

## A useful change

- Fix a demonstrated failure or simplify an existing rule.
- Preserve user intent, constraints and action permissions.
- Keep straightforward tasks one-shot.
- Give additional stages a specific purpose and a stop condition.
- Avoid provider-specific claims without evidence.
- Do not add runtime dependencies for a text-only skill.

Check the cases in [EXAMPLES.md](EXAMPLES.md), document what you actually tested, and use [EVALUATION.md](EVALUATION.md) for comparisons. A plausible prompt is not proof of improved output.

Small, focused pull requests are easiest to review. Contributions are under the project's MIT license.
